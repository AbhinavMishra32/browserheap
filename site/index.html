Still a full browser

          
Sites work the way they do in Chrome

          
Lightweight engines use less memory by not rendering pages. Browserheap is Chromium, the same engine every agent tool uses, so pages look and behave as they do in Chrome.

What a tab wakes up with

      

        
Where it was
The page's scroll and every scrolled panel's, focus and selected text. Feeds load again what they had loaded.

        
What was filled in
Text fields, checkboxes and dropdowns, as the agent left them.

        
Its history
Back and Forward go where they went before the tab slept.

        
Logins and storage
Cookies, localStorage, IndexedDB and the tab's own sessionStorage. Snapshot refs like e12 still point at the same element.

      

    

  


  

    

      

        
        
      

    

  


  

    

      
Agents don’t close tabs

      
Agent tools work around it by closing tabs or restarting Chrome, and either way the agent loses its place. Browserheap lets the tabs sleep instead.

    

  


  

    

      

        
Sleeping tabs

        
Two tabs awake, the rest asleep

        
The two tabs your agent used last are live Chromium pages. Every other tab sleeps: it gives back its memory and keeps everything else, from scroll and fields to history and logins. Touch it and it wakes as it was, in about a quarter of a second. Asleep, it's still searchable: findInTabs() looks through everything your agent has read, and says how old each page is.

docs.isAsleep()            // true
await docs.title()         // "React", without waking it

await docs.getByRole("link", { name: "Learn" }).click()
// docs wakes in ~0.3 s and the click lands

        

      

      

        
Handles that survive sleep

        
Pages keep working while they sleep

        
Other agent browsers hand out raw pages that go stale when a tab closes. Browserheap's pages and locators belong to the tab, so a page kept in a variable keeps working while its tab sleeps and wakes underneath.

Works with your agent

        
A skill, a CLI, or an SDK

        
Drop the skill into Claude Code or Codex and your agent learns the loop: open a page, read its snapshot, act with Playwright-style code, check what changed. Or drive it from a shell, or build it into your own agent with startSession().

const session = await startSession({ maxLive: 2 })

  return session.run(code)   // text and images back
